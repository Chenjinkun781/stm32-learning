# 6-3 PWM 渐变与 LED 呼吸灯练习

使用 TIM2 通道 1 输出占空比渐变的 PWM 信号。将适当的 LED 电路接到 PWM 引脚，可以观察周期性的亮度变化。

## 程序行为

- PA0 / TIM2_CH1 为 PWM 输出，配置为复用推挽。
- 在设计的 72 MHz TIM2 时钟下，`PSC=719`、`ARR=99`，PWM 频率为 `72000000 / 720 / 100 = 1000 Hz`。
- 主循环将 CCR1 从 0 调到 100，再从 100 调回 0；每步调用 `Delay_ms(5)`。
- 两段各有 101 个步骤，一轮设计延时约为 1.01 秒，实际还包含程序执行时间。
- PWM1 模式、高电平有效；CCR1 在 0–100 范围对应约 0%–100% 占空比。
- OLED 仅初始化，当前主程序没有显示文字或数值。

实际 LED 亮暗变化方向取决于接法。程序直接控制 PA0 的 PWM，并未调用另一个 LED 驱动模块。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| PWM 输出 | PA0 / TIM2_CH1 |
| OLED SCL、SDA | PB8、PB9 |
| 公共地 | GND |

LED 电路应使用合适的限流电阻；也可以使用示波器或逻辑分析仪观察 PA0 的波形。

## 主要文件

- `User/main.c`：占空比渐变循环。
- `Hardware/PWM.c`、`PWM.h`：PWM 初始化与 CCR1 设置。
- `Hardware/OLED.c`：OLED 驱动。
- `Start/`、`Library/`、`System/`：启动文件、标准外设库和延时工具。

## 开发环境与打开方式

工程目标为 STM32F103C8，使用 Keil µVision / MDK、ARM Compiler 6.24 和 `Keil.STM32F1xx_DFP.2.4.1`。用 Keil 打开 `Poject.uvprojx`，检查本机编译器、器件包和下载器设置后，再编译、下载。
