# 3-4 按键控制 LED

用两个按键分别控制两个 LED 的亮灭翻转，练习 GPIO 输入、输出和简单软件消抖。工程基于 STM32F103C8 和 STM32F10x 标准外设库。

## 功能

- LED1 接 PA1、LED2 接 PA2，推挽输出、低电平点亮，上电默认熄灭。
- 按键 1 接 PB1、按键 2 接 PB11，上拉输入，按下时为低电平。
- 按一次按键 1 翻转 LED1，按一次按键 2 翻转 LED2，互不影响。

## 原理

- `LED__Init()` 把 PA1、PA2 配置为推挽输出并输出高电平（熄灭）。
- `Key_Init()` 把 PB1、PB11 配置为上拉输入。
- `Key_GetNum()` 检测到低电平后先延时 20 ms 消抖，再等待松手并再延时 20 ms，最后返回键号。
- `LED1_Turn()`、`LED2_Turn()` 通过读输出数据寄存器判断当前状态，再取反。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| LED1 | PA1 |
| LED2 | PA2 |
| 按键 1 | PB1 |
| 按键 2 | PB11 |
| 公共地 | GND |

按键模块如果没有外部上拉，需要靠芯片内部上拉；接线以实际模块为准。

## 开发环境

- 芯片：STM32F103C8。
- 工具：Keil µVision / MDK-ARM。
- 编译器：ARM Compiler 6.24（ARMCLANG）。
- 器件包：`Keil.STM32F1xx_DFP.2.4.1`。
- 外设库：STM32F10x 标准外设库。

## 打开工程

1. 用 Keil µVision 打开当前目录的 `Poject.uvprojx`。
2. 确认编译器和器件包配置，按开发板配置下载器。
3. 编译并下载，分别按两个按键观察 LED 是否翻转。

## 主要文件

| 文件或目录 | 内容 |
| --- | --- |
| `User/main.c` | 主循环读取键值并翻转 LED |
| `Hardware/LED.c` | LED 初始化、亮灭与翻转 |
| `Hardware/Key.c` | 按键初始化与消抖读取 |
| `System/Delay.c` | 毫秒延时函数 |
| `Start/` | 启动文件、系统时钟与 CMSIS |
| `Library/` | STM32 标准外设库 |
