# 6-1 TIM2 正向计时器

使用 STM32F103C8 的 TIM2 定时中断，让计数值从 0 开始递增，并在 OLED 上显示。按照工程中的 72 MHz 时钟配置，设计更新周期为 1 秒。

## 功能

- 上电后初始化 OLED 和 TIM2，自动开始计时。
- TIM2 每次产生更新中断，`Num` 增加 1。
- OLED 第一行显示 `Num:` 和五位十进制计数值。
- 当前版本没有暂停、按键清零、倒计时、掉电保存或时分秒格式转换。

## 定时原理

`System/Timer.c` 使用 TIM2 内部时钟、向上计数模式，设置：

- 预分频器：`7200 - 1`。
- 自动重装值：`10000 - 1`。
- 开启更新中断，并在 `User/main.c` 的 `TIM2_IRQHandler()` 中递增计数。

工程的系统时钟按 72 MHz 配置，APB1 分频为 2，TIM2 时钟为 72 MHz。更新周期按下式计算：

```text
更新周期 = (PSC + 1) × (ARR + 1) / TIM2 时钟
         = 7200 × 10000 / 72000000
         = 1 秒
```

实际计时精度取决于开发板的时钟源及配置；本次未在开发板上测量计时误差。

## OLED 接线

| 功能 | STM32 引脚 |
| --- | --- |
| SCL | PB8 |
| SDA | PB9 |
| 公共地 | GND |

OLED 供电按实际模块规格接线。计时使用内部时钟，不需要额外的计数输入引脚。

## 开发环境

- 芯片：STM32F103C8。
- 工具：Keil µVision / MDK-ARM。
- 工程记录的编译器：ARM Compiler 6.24（ARMCLANG）。
- 工程记录的器件包：`Keil.STM32F1xx_DFP.2.4.1`。
- 外设接口：STM32F10x 标准外设库。
