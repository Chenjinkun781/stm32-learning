# 6-4 PWM 舵机角度控制

用 PWM 脉宽表示目标角度，通过按键切换角度，并在 OLED 上显示当前角度命令。

## 程序行为

- 舵机信号由 PA1 / TIM2_CH2 输出。
- 按设计的 72 MHz TIM2 时钟，`PSC=71`、`ARR=19999`，计数分辨率为 1 微秒，周期 20 毫秒，即 50 Hz。
- `Servo_SetAngle(Angle)` 按 `Angle / 180 × 2000 + 500` 计算比较值，将 0–180° 映射为 500–2500 微秒脉宽。
- PB1 按键按下并释放后，目标角度增加 30°；超过 180° 后回到 0°。
- OLED 显示 `Angle:` 和目标角度。这个数值是命令值，程序没有角度反馈测量。
- PB11 的第二按键虽然被扫描，但主程序没有为键 2 安排动作。

## 原始代码中的待改进项

初始化阶段调用了 `Servo_SetAngle(1500)`。该函数的参数单位是角度，1500 超出当前设计的 0–180° 范围，换算结果约为 17166 微秒，而不是 1500 微秒。随后主循环才使用初值为 0 的 `Angle` 设置 PWM。

本次按原样归档，没有修正这一行。后续应明确区分“角度”和“脉宽”的接口，并为角度参数增加范围检查。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| 舵机驱动信号 | PA1 / TIM2_CH2 |
| 按键 1 | PB1，上拉输入，按下接 GND |
| OLED SCL、SDA | PB8、PB9 |
| 舵机、电源与开发板公共地 | GND |

舵机供电按实际型号和电流需求连接；500–2500 微秒为本代码采用的映射范围，实际可用角度与脉宽范围需按舵机规格确认。

## 主要文件

- `User/main.c`：按键处理、角度命令和 OLED 显示。
- `Hardware/Servo.c`、`Servo.h`：角度到脉宽的映射。
- `Hardware/PWM.c`、`PWM.h`：TIM2_CH2 PWM。
- `Hardware/Key.c`：按键扫描。

## 开发环境与打开方式

STM32F103C8，Keil µVision / MDK，ARM Compiler 6.24，`Keil.STM32F1xx_DFP.2.4.1`。工程文件为 `Poject.uvprojx`。
