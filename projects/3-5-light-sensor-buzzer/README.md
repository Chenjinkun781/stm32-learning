# 3-5 光敏传感器控制蜂鸣器

读取光敏传感器模块的数字输出，根据光照情况控制蜂鸣器开关，练习 GPIO 输入与模块化驱动。工程基于 STM32F103C8 和 STM32F10x 标准外设库。

## 功能

- 光敏传感器数字输出 DO 接 PB13，配置为上拉输入。
- 蜂鸣器接 PB12，推挽输出、低电平发声。
- 主循环不断读取传感器：读到 1 时蜂鸣器响，读到 0 时关闭。

## 原理

- 光敏传感器模块内部用比较器把光照强弱变成高低电平，DO 输出数字量。
- `LightSensor_Get()` 直接返回 PB13 的输入电平。
- `Buzzer_ON()` / `Buzzer_OFF()` 分别把 PB12 拉低、拉高。
- 实际“亮 / 暗”对应输出 1 还是 0，取决于模块上的电位器调节。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| 光敏传感器 DO | PB13 |
| 蜂鸣器信号 | PB12 |
| 电源 / 公共地 | 按模块规格接 |

## 开发环境

- 芯片：STM32F103C8。
- 工具：Keil µVision / MDK-ARM。
- 编译器：ARM Compiler 6.24（ARMCLANG）。
- 器件包：`Keil.STM32F1xx_DFP.2.4.1`。
- 外设库：STM32F10x 标准外设库。

## 打开工程

1. 用 Keil µVision 打开当前目录的 `Poject.uvprojx`。
2. 确认编译器和器件包配置，按开发板配置下载器。
3. 编译并下载，用手遮挡传感器或调节电位器，听蜂鸣器变化。
