# 5-2 旋转编码器计数

使用 STM32F103C8 读取旋转编码器的两路信号，通过外部中断判断方向，再把累计计数显示在 OLED 上。

## 功能

- 编码器的两路信号分别接入 PB0 和 PB1，配置为上拉输入。
- EXTI0 和 EXTI1 检测上升沿，在中断中读取另一路电平，决定计数增加或减少。
- 主循环读取本次计数增量并累加到 `Num`。
- OLED 第一行显示 `Num:` 和带正负号的五位数值。

计数表示程序识别到的信号变化，未换算为转数或角度；每个机械刻度对应多少计数取决于编码器的信号和实际测试。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| 编码器通道 A / CLK | PB0 |
| 编码器通道 B / DT | PB1 |
| OLED SCL | PB8 |
| OLED SDA | PB9 |
| 模块公共地 | GND |

A、B 为本说明对两路信号的命名；实际模块标注以硬件为准。调换编码器两路信号后，计数方向会改变。模块供电应按各自规格接线，编码器信号须与 STM32 输入电平兼容。

## 开发环境

- 芯片：STM32F103C8。
- 工具：Keil µVision / MDK-ARM。
- 工程记录的编译器：ARM Compiler 6.24（ARMCLANG）。
- 工程记录的器件包：`Keil.STM32F1xx_DFP.2.4.1`。
- 外设接口：STM32F10x 标准外设库。

使用其他工具版本时，可能需要在工程选项中重新选择已安装的编译器和器件包。

## 打开工程

1. 用 Keil µVision 打开当前目录的 `Poject.uvprojx`。
2. 检查已安装的 STM32F1 器件包和 ARM Compiler 设置。
3. 按接线表连接编码器与 OLED，再编译、下载到开发板。
4. 转动编码器，观察屏幕上的数值变化；检查相反方向是否对应相反的变化。

工程文件沿用原始名称 `Poject.uvprojx`。
