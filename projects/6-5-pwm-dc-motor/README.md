# 6-5 PWM 直流电机调速与方向控制

使用 PWM 控制直流电机驱动命令的大小，两路 GPIO 表示方向，通过按键循环调整有符号命令，并在 OLED 上显示。

## 程序行为

- `Speed` 初始为 0。PB1 每按下并释放一次，命令增加 20；从 +100 跳到 -100，再逐步增加。
- OLED 显示如 `Speed:+020`、`Speed:-100`。显示值是控制命令，程序没有测量实际转速，也没有转速闭环反馈。
- PA2 / TIM2_CH3 输出 PWM。在设计的 72 MHz TIM2 时钟下，`PSC=719`、`ARR=99`，PWM 频率为 1 kHz。
- PWM 占空比由 `Speed` 的绝对值决定；当前命令范围内，对应约 0%–100%。
- 非负命令时 PA4 为低电平、PA5 为高电平；负命令时 PA4 为高电平、PA5 为低电平。
- 正负命令对应的实际旋转方向取决于电机和驱动模块接线，不指定观察方向下的顺时针或逆时针。
- PB11 的第二按键被扫描，但当前主程序不处理键 2。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| 驱动模块 PWM / 使能输入 | PA2 / TIM2_CH3 |
| 驱动模块两路方向输入 | PA4、PA5 |
| 按键 1 | PB1，上拉输入，按下接 GND |
| OLED SCL、SDA | PB8、PB9 |
| 驱动模块、信号电源与开发板公共地 | GND |

PA2、PA4、PA5 用于连接电机驱动模块的控制输入，电机经驱动模块供电。驱动芯片型号、供电及控制电平要求按实际设备确认，源码没有指定完整实物方案。

## 主要文件

- `User/main.c`：命令循环、按键处理和显示。
- `Hardware/Motor.c`、`Moter.h`：方向引脚和 PWM 命令设置。头文件保留原始拼写 `Moter.h`。
- `Hardware/PWM.c`、`PWM.h`：TIM2_CH3 PWM。
- `Hardware/Key.c`：按键扫描。

## 开发环境与打开方式

STM32F103C8，Keil µVision / MDK，ARM Compiler 6.24，`Keil.STM32F1xx_DFP.2.4.1`，STM32F10x 标准外设库。工程文件为 `Poject.uvprojx`。
