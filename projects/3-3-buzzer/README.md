# 3-3 蜂鸣器

用 GPIOB 的 PB12 控制有源蜂鸣器，按“短鸣 + 长停”的节奏发声。工程基于 STM32F103C8 和 STM32F10x 标准外设库。

## 功能

- 上电后把 PB12 配置为推挽输出，默认输出高电平（蜂鸣器关闭）。
- 主循环依次执行：响 100 ms、停 100 ms、响 100 ms、停 100 ms、响 100 ms、停 700 ms，然后重复。
- 效果是三声短鸣后停顿一段时间。

## 原理

- 有源蜂鸣器内部自带振荡源，只要给电就能发声，不需要 PWM。
- `GPIO_ResetBits(GPIOB, GPIO_Pin_12)` 输出低电平打开蜂鸣器，`GPIO_SetBits()` 输出高电平关闭。
- 打开/关闭的时间由 `Delay_ms()` 控制。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| 蜂鸣器信号 | PB12 |
| 电源 / 公共地 | 按蜂鸣器模块规格接 |

无源蜂鸣器不能靠直流电平发声，需要 PWM 驱动；本工程对应有源蜂鸣器模块。

## 开发环境

- 芯片：STM32F103C8。
- 工具：Keil µVision / MDK-ARM。
- 编译器：ARM Compiler 6.24（ARMCLANG）。
- 器件包：`Keil.STM32F1xx_DFP.2.4.1`。
- 外设库：STM32F10x 标准外设库。

## 打开工程

1. 用 Keil µVision 打开当前目录的 `Poject.uvprojx`。
2. 确认编译器和器件包配置，按开发板配置下载器。
3. 编译并下载，听蜂鸣器的节奏是否和代码一致。

## 主要文件
