# 6-2 TIM2 外部时钟脉冲计数

在 [6-1 内部时钟计时练习](../6-1-timer/README.md) 的基础上，将 TIM2 改为外部时钟模式 2，通过 PA0 接收外部脉冲，观察硬件计数器和更新中断次数。

两份工程作为独立练习并列保存，均有自己的 Keil 工程文件，可以分别打开、编译和比较。

## 功能与计数过程

- PA0 配置为上拉输入，作为 TIM2 的 ETR 外部时钟输入。
- 外部输入上升沿有效；ETR 不分频，数字滤波参数为 `0x00`。
- TIM2 向上计数，`PSC = 0`、`ARR = 9`。每个有效脉冲使硬件计数器 `CNT` 前进，计数值在 0–9 之间循环。
- 每收到 10 个有效脉冲，计数器回到 0 并产生更新中断，软件变量 `Num` 增加 1。
- `Timer_GetCounter()` 读取当前的 TIM2 硬件计数值。

更新速度由外部脉冲决定，没有固定的 1 秒周期。如果输入频率为 `f` Hz，更新中断的理论间隔为 `10 / f` 秒。

## 与 6-1 的比较

| 内容 | 6-1 内部时钟 | 6-2 外部时钟 |
| --- | --- | --- |
| 计数时钟来源 | TIM2 内部时钟，工程配置为 72 MHz | PA0 / TIM2_ETR 上的外部脉冲 |
| 时钟配置函数 | `TIM_InternalClockConfig()` | `TIM_ETRClockMode2Config()` |
| 预分频器 PSC | 7199 | 0 |
| 自动重装值 ARR | 9999 | 9 |
| 更新中断条件 | 正常时钟配置下每 1 秒一次 | 每 10 个有效外部脉冲一次 |
| `Num` 的含义 | 按设计周期累计的秒数 | 累计的更新中断次数 |
| OLED 数值 | `Num` | `Num` 与当前 `CNT` |

与 6-1 相比，主要源码变化位于 `User/main.c`、`System/Timer.c` 和 `System/Timer.h`。

## 接线

| 功能 | STM32 引脚 |
| --- | --- |
| 外部脉冲输入 / TIM2_ETR | PA0 |
| OLED SCL | PB8 |
| OLED SDA | PB9 |
| 脉冲源、OLED 与开发板公共地 | GND |

输入信号电平应符合 STM32 引脚规格，模块供电按实际设备规格接线。当前程序不生成输入脉冲；脉冲源来自实际连接的设备。

## 当前显示情况

原始主程序连续在 OLED 的第 1 行第 1 列写入 `Num:` 和 `CNT:`，后者覆盖前者。因此当前行为是：

- 第 1 行标签显示 `CNT:`，但从第 5 列开始显示的是 `Num`，即更新中断累计次数。
- 第 2 行第 5 列显示当前硬件 `CNT`，这一行没有对应标签。

本次记录保留原源码。后续可以将写入 `CNT:` 的位置调整到第 2 行第 1 列，使标签和数值对应。

## 开发环境与打开方法

- 芯片：STM32F103C8。
- 工具：Keil µVision / MDK-ARM。
- 工程记录的编译器：ARM Compiler 6.24（ARMCLANG）。
- 工程记录的器件包：`Keil.STM32F1xx_DFP.2.4.1`。
- 外设接口：STM32F10x 标准外设库。

用 Keil µVision 打开当前目录的 `Poject.uvprojx`，检查本机的编译器、器件包和下载器设置，再编译并下载到开发板。输入低速外部脉冲，观察 `CNT` 是否按 0–9 循环，以及 `Num` 是否在每次循环后增加 1。
