## 使用方法

进入对应项目目录，用 Keil µVision 打开 `.uvprojx` 工程文件；具体接线和开发环境见项目说明。

## 目录

- `projects/`：各阶段的代码和工程文件。
- `logs/`：每次学习记录。
- `.gitignore`：排除编译输出和本机编辑器偏好。

工程中附带的 ST、ARM 库文件保留原有版权声明。
